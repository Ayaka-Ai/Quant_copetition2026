## 价格和金额基准

价格还原只使用已识别为真实股数拆股、且边界价格支持该来源解释的因子。若拆股后的来源价格已显示完整除权跳变，不能再乘一次因子；此类歧义会阻塞处理。实际拆股股数采用有理数运算，尤其 1:3 不能先四舍五入成小数再取整，否则原有 3 股可能被误判为不足 1 股。

对除息日 e，令 `C` 为来源 Close、`A` 为来源 Adj Close、`d` 为来源分红，检查：

```text
(A[e] / C[e]) / (A[e-1] / C[e-1]) ≈ C[e-1] / (C[e-1] - d)
```

相对误差门槛为 `1e-5`，用于识别来源金额与来源价格的单位关系，不据此自动修复价格。若没有前一交易日、存在多笔未解释分配或关系不一致，该事件不接受。来源分红与价格在同一拆股调整基准时，乘除息日之后的已核实真实拆股因子，还原当时每股现金金额；涉及未解释复杂因子的早期金额不按此式硬算。

## 账户接口与记账顺序

```python
from quant_backtest import CorporateAction, simulate_portfolio

# 1:3 的真实拆股应提供精确分子和分母。
action = CorporateAction(
    event_id="issuer_event_id", symbol="AAA", effective_session=day,
    kind="split", available_at=modeled_open_time,
    ratio_numerator=1, ratio_denominator=3,
    verified=True, evidence="来源与股数基准检查依据；公开模型可用时间假设",
)
result = simulate_portfolio(sessions, prices, targets, config,
                            corporate_actions=[action])
```

`verified=True` 是调用方对该事件在所声明模型中的类型及单位检查，不等于供应商历史发布时间或严格 V1 的验证状态。事件必须属于显式日历，使用实际股数口径；有事件的账户只支持常规时段次日开盘模式，不混入旧 UTC 收盘代理。

普通事件顺序为：拆股及待执行目标换算 → 按前收盘持有资格计入分配现金 → 开盘碎股现金补偿 → 普通卖出 → 普通买入 → 收盘估值。同日有未处理复杂行动时优先阻塞，不先按不明股数支付分红。

- 除息日前已持有者获得分配，当天卖出仍保留资格；除息日开盘新买入者不获得该次分红。零持有资格的未知现金事件记录为不适用，不捏造现金。
- 分红使用税前除息日现金代理，不模拟实际支付日、预提税或自动红利再投资；新增现金不能提高原信号已决定的目标股数。
- 拆股保持总成本基础不变，并按累计精确比率换算信号时目标。股数是机械换算，不由未来开盘价格反推。
- 碎股按当日还原开盘价作研究现金补偿，无额外费用或滑点；按比例移出碎股成本，差额记录为已实现盈亏。缺少补偿开盘价时阻塞，不能编造现金。
- 完全相同的事件重复输入只记一次；同 ID 的冲突版本、同日未整合的多条拆股直接报错。来源不同组件的合并须有明确依据，不能重复计算分红与资本分配。

新增 `corporate_actions.csv` 保存逐事件现金、股数、成本和状态；订单另保存原信号股数与拆股后股数。每日检查：现金等于初始资金加成交现金流加公司行动现金流；净值变化等于已实现盈亏、累计分配收入与未实现盈亏之和。
