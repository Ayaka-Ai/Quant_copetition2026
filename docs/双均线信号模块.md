# 双均线信号模块

已实现并在现有 B 组数据上运行。Python 3.8+、仅标准库，无需 API key、联网或额外依赖。

## 运行

在仓库根目录执行：

```bash
python3 -m examples.run_signals
```

默认读取 `experiments/databento_smoke/data/b`，写入 `outputs/ma_signals_b/signals.csv` 和 `summary.json`。重复运行会覆盖这两个派生文件，原始行情不变。outputs/ 已加入 Git 忽略列表。可用 `--sample-dir`、`--output-dir` 指定其他目录。

## 规则

每只股票独立计算最近 5 条和 20 条已完成日柱的收盘价简单平均。窗口按记录数计数，不是自然日，不补缺口。短均线严格高于长均线时 target_position=1；低于或等于时为 0。前 19 条记录为 warmup，target_position 留空，不把数据不足当成空仓信号。短均线从第 5 条起可以显示，但到第 20 条才产生有效目标。

这是每天输出目标状态的规则，不是只在交叉当天输出订单。首次有效信号可直接为 1；具体首次建仓、后续调仓由未来成交模块处理。

1 表示该标的希望做多，0 表示希望空仓，**不是把账户 100% 资金分给这只股票**。多个标的同时为 1 时，必须由后续组合模块决定权重。target_changes 仅统计有效目标序列相邻状态的变化，不包含首次有效目标，也不是成交次数。

## 信号字段

| 字段 | 含义 |
|---|---|
| symbol | 标的 |
| provider_bar_date | 供应商 UTC 日柱日期 |
| bar_end_utc | 完整柱区间的结束时间 |
| signal_not_before_utc | 信号最早可能可用的时间下界，目前等于 bar_end_utc |
| close | 当前柱未复权收盘价 |
| short_ma / long_ma | 尾随 5 条／20 条均线，不足窗口时留空 |
| status | warmup 或 ready |
| target_position | 空值、0 或 1 |

信号使用当前完整柱及此前记录，不能在当前柱开始时使用。实际发布时间未知，因此 signal_not_before_utc 不保证该时刻已经收到行情；后续回测仍需明确发布延迟和成交时刻。7 月 29 日的首次信号最早在 7 月 30 日 00:00 UTC 完整，不是 7 月 29 日开盘就已知。

## 程序调用

```python
from quant_data import load_daily_bars
from quant_signals import moving_average_signals

data = load_daily_bars('experiments/databento_smoke/data/b')
signals = moving_average_signals(data.bars, short_window=5, long_window=20)
```

输入采用统一接口的 DailyBar。同一标的必须按时间递增且无重叠，重复或倒序会报错；输出按柱结束时间及标的排序。函数只依赖行情记录，测试可以使用合成数据。数据加载时若先截短日期范围，会失去此前预热历史；需要某段信号时应先加载足够历史、计算后再筛选输出。
