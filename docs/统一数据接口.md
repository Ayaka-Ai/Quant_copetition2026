这一步只统一数据读取和字段含义。策略通过 `quant_data.load_daily_bars` 读取行情，不直接读取供应商 CSV，也不自行维护 instrument_id 映射。下载、策略信号和成交记账分别实现。

同日新增 `quant_data.action_basis.prepare_action_basis`，按独立核查清单提供公开研究还原价格、事件输入和未解决项，见 [公司行动核查与记账](公司行动核查与记账.md)。该接口不修改本页旧接口及严格 V1 准备状态。

## 快速使用

Python 3.8+，仅标准库，无需安装新依赖。以下代码从仓库根目录运行；sample_dir 也可以传绝对路径。

```python
from quant_data import load_daily_bars

data = load_daily_bars(
    'experiments/databento_smoke/data/b',
    symbols=['AAPL', 'MSFT'],
    start='2026-09-01',
    end='2026-10-01',
)
print(data.info)
for bar in data.bars:
    print(bar.symbol, bar.provider_bar_date, bar.close)
```

日期筛选统一为 **左闭右开 `[start, end)`**，按供应商 UTC 柱日期筛选。省略 symbols 表示全部标的；省略日期边界表示不限制对应一侧。未知标的、空标的列表或无效参数报错；合法范围无匹配时返回空 tuple，调用方须处理。

运行完整示例：

```bash
python3 -m examples.inspect_daily
```

## 返回字段

`BarDataset` 包含 `info`（数据口径）和 `bars`（不可变记录 tuple）。记录按 `(bar_start_utc, symbol)` 升序排列，同一标的和日期只能有一条。

| DailyBar 字段 | Python 类型 | 约定 |
|---|---|---|
| symbol | str | AAPL、MSFT、SPY 等原始证券代码 |
| provider_bar_date | datetime.date | UTC 柱日期，不命名为交易所交易日 |
| bar_start_utc | 带 UTC 时区的 datetime | 柱区间起点，包含 |
| bar_end_utc | 带 UTC 时区的 datetime | 柱区间终点，不包含 |
| open / high / low / close | Decimal | 美元原始未复权价格；保留小数精度 |
| volume | int | 组成场所的成交股数，正整数 |

价格使用 Decimal；如研究库需要 float，由策略适配层显式转换，不修改原始数据。未来接入其他资产或数据源，需要先验证单位和语义，不能沿用当前美元、股数的假设。

`info` 明确记录 contract_version、来源、dataset、schema、currency、price_adjustment、session、volume_scope、availability、原始请求起止及原始文件 SHA256。筛选后 info 的 source_start/end 仍描述完整来源范围，而非筛选结果范围。

当前适配器只支持本项目下载脚本产生的 EQUS.MINI / ohlcv-1d / pretty_px=true 缓存。现有 manifest 未单独存储 pretty_px，美元单位依赖已审查的下载脚本约定；不要把任意外部 CSV 放入这个目录冒充兼容缓存。

## 时间与可用性

日柱按 UTC 自然日聚合，不能把 open/close 当成美东 09:30/16:00 的价格。bar_end_utc 只是该柱最早可能完整的边界，不是供应商实际发布时刻。availability 明确标记实际发布时间未知。

接口返回历史数据集合，不是防止未来信息泄漏的回放引擎。后续回测引擎必须限制策略当时可见的数据，并显式设定发布延迟与成交假设；不能仅因为拿到了完整数组，就在柱起点使用该柱的收盘价。

## 校验与缺失处理

读取时先校验整个原始文件，再应用筛选。检查文件大小和 SHA256、请求范围、字段、UTC 午夜时间戳、映射有效期、重复记录、有限正价格、OHLC 关系和正整数成交量。不依赖可能过期的 normalized.csv 或验收通过标志。

接口不补齐缺失日期、不前向填充价格、不制造零成交量柱，也不复权或自动过滤交易时段。日期完整性检查仍由实验验收脚本负责；通用读取接口不内置 B 组三个月的日历。异常输入抛出 DataContractError，策略不应捕获后默默继续运行。

SHA256 用于检测原始 CSV 与本地下载记录是否一致，不是供应商签名；现有 manifest 没有映射文件的哈希，不能证明映射文件从未修改。映射本身会在每条记录解析时验证。

## 扩展方式与团队约定

1. 策略只依赖这里的 DailyBar 字段及 info，不依赖 Databento 原始列名或 instrument_id。
2. 新数据供应商增加单独适配器，明确时区、单位、复权与市场覆盖；不静默混合不同口径。
3. 将来添加复权价、真实发布时间或常规时段日线时保留原始字段，并升级接口版本，避免改变旧字段含义。
4. 原始行情仍保留在本地被 Git 忽略的 data/ 目录。本次未上传代码或数据。
