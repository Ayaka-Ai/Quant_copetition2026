# 本地模拟账户：B 组日线

## 运行与结果文件

从仓库根目录执行（Python 3.8+，仅标准库）：

```bash
python3 -m examples.run_account
python3 -m unittest discover -s tests -v
```

只读取已下载 B 组缓存，不需要 API key、真实账户或真实资金。重复运行覆盖 `outputs/account_b/` 下的派生结果；原始行情不变，outputs/ 已被 Git 忽略。本次代码和结果均未上传 GitHub。

| 文件 | 内容 |
|---|---|
| orders.csv | 信号日期、时间下界、委托方向与股数、状态、实际成交数量 |
| trades.csv | 实际模拟成交、参考价格、滑点后价格、手续费、现金变动及成交后持仓 |
| daily.csv | 每日现金、市值、资产、净值、盈亏、累计费用和回撤 |
| positions.csv | 每日每只标的的股数、成本、现金、已实现及未实现盈亏 |
| summary.json | 参数、源数据校验值、结果与局限 |

## 固定假设

- 初始资金 100,000 美元。AAPL、MSFT 各分配 33,333.33，SPY 分配 33,333.34；三个独立资金子账户，不互相挪用资金。
- 沿用 5／20 日双均线：预热不下单；首次有效目标和之后目标变化时检查是否需要委托。持续做多期间不每日调仓；空仓资金留在对应子账户。
- 做多、整数股、不融资、不做空。买入时尽量使用该子账户现金；退出时卖出全部持仓。
- 手续费假设为每股 0.005 美元、每笔最低 1 美元。参考 [IBKR 官方美股佣金页面](https://www.interactivebrokers.com/en/pricing/commissions-stocks.php) 的量级，但这是简化模拟，未实现完整费率上限、卖出监管费或其他实际收费规则，不代表具体账户报价。
- 买入价为参考价 × 1.0005，卖出价为参考价 × 0.9995，即双边各 5 个基点滑点。这个参数是未经分钟/盘口数据校准的演示假设。
- 使用 Decimal 保留计算精度，不逐笔按券商规则舍入到美分。摘要展示时可以四舍五入。

## 时间与成交规则

完整第 t 根日柱计算信号；按当时的子账户现金、该柱 close、手续费及买入滑点确定整数委托数量。该标的下一根观测日柱的 close 才作为成交参考价。**不会先看到下一根价格再决定期望下单数量。**

若实际代理成交价上涨、现金不够，成交时仅缩减至可支付股数，剩余委托取消，不借钱；若下跌，不追加原委托之外的数量。没有可交易股数时记录 no_quantity。期末尚无下一根柱的委托保留 pending_end_of_sample，不虚构未来成交；期末持仓按最后 close 估值，不强制平仓。

这里的 fill_proxy_time_utc 是下一根柱区间终点，仅为演示记账时间。原始 close 对应的实际最后一笔成交时刻和供应商发布延迟未知，因此不表示可在该时刻按该价真实成交，也不是美股官方收盘竞价或次日 09:30 成交。

同一标的执行上根信号委托后，再处理当前柱的新信号。没有假设可提前看到当前柱收盘。当前演示要求所有标的日期覆盖一致；缺少行情就报错，不自动补价。没有成交量约束或订单簿模型，现金不足导致的缩量也不是对真实市场部分成交的建模。

## 记账规则

买入成本包含手续费；卖出从持仓成本中移除相应成本，卖出净收入减去移除成本构成已实现盈亏。未实现盈亏为当前市值减持仓成本。

每天检查：

- 现金 = 初始现金 + 所有成交现金变动。
- 总资产 = 现金 + 持仓市值。
- 总资产 − 初始现金 = 已实现盈亏 + 未实现盈亏。
- 各子账户现金及股数不得为负。

滑点已体现在成交价和现金中，summary 的 slippage_cost 仅作成本归因，不能再扣一次。分红、拆股、税费、现金利息、资金结算等待均未实现，所以结果不是总回报口径。

## 验证与使用边界

共 19 项单元测试通过，其中新增 6 项账户测试验证手算往返交易、下一柱成交、手续费、滑点不重复扣除、现金不足缩量、子账户独立、禁止期末强制虚构成交及未来行情不影响历史账目。

另从导出的交易 CSV 独立重建现金和股数，逐日核对 64 个日期的账目；实际 B 组全部 64 个按日截断样本的历史净值均与全样本对应历史一致。

这证明当前约定下的模拟流程和账目能跑通，不证明策略在真实市场能获得相同收益。UTC 未复权日柱、未知发布时刻、简化滑点与公司行动缺失等限制仍然存在。本阶段未调参、未做样本外验证，不能把这三个月的演示结果当作策略有效性的证据。
