# CLEAR-US 阶段成果与模拟接口讨论报告

整理日期：2026-11-09（香港时间）｜会议日期：2026-11-13，周五

## 一、现阶段结论

项目已经达到“可演示、可复现的本地研究与仿真内核”阶段，可以接入按现有格式整理的历史／合成行情，计算信号、生成完整目标仓位，在本地模拟账户中形成拟订单、模拟成交并核对现金和净值。

还不能直接连接实时模拟行情或券商模拟账户自动下单。行情适配、券商执行、持续运行及外部账户对账仍需实现并验收。当前策略配置均关闭券商路由；本次按讨论要求收口，不接通外部账户、不继续增加策略模块。

现有真实行情缓存截至2026-11-03，不是今天的实时行情，不能据此生成当日交易指令。前向模拟需要先明确来源、补齐所需历史并取得截至目标交易日的数据。

| 使用层级 | 当前判断 |
|---|---|
| 本地合成数据／历史缓存回放 | 已贯通，可演示和核对 |
| 外部日线文件按规范导入，生成拟订单 | 内核可支持；具体来源仍需适配与数据验收 |
| 持续接收模拟行情，前向记录但不下单 | 待实现数据更新、状态持久化和运行调度 |
| 券商模拟账户自动下单 | 待执行适配器、订单状态回写及端到端对账 |
| 完整指数增强、实盘或收益有效性认证 | 尚未达到 |

## 二、已经实现了什么

1. **数据与账本**：固定股票池、交易日历、公开日线缓存、来源哈希与时间证据；普通分红、拆股和碎股记账；复杂或不明权益事件明确阻塞。原始股票池503个代码，SPY另作基准。
2. **信号与组合**：20日动量；14个传统因子；行业内标准化；统一SignalScore；行业与发行人约束；每周信号及下一交易日执行约定。
3. **实际持仓换仓**：TopK Drop读取模拟成交后的实际持仓，区分退出、补位和常规替换；0.15个截面标准差优势门槛、最多20%常规替换数量。
4. **模拟执行与账目**：共享现金、先卖后买、整数股、简化佣金与滑点、现金不足缩量、缺价取消；单独变体支持双边成交金额及单股容量代理预算。这里只是本地成交模型，不是券商订单生命周期。
5. **风险计算**：91期60日Beta、52期252日对角收缩协方差；目标及实际持仓的波动、净资产口径Beta、方差贡献；风险数据按真实／模型时间隔离。
6. **权重优化接口**：基于预先选股集合的非负、总仓位、单股及行业约束优化；不收敛或数据不全时不生成新目标。当前80%／20只／4%配置为唯一等权解。
7. **审计与复现**：信号、目标、订单、成交、公司行动、持仓、净值、风险诊断、求解状态及版本指纹均有输出。最近一次完整验证172项测试通过。

## 三、已有结果与应如何理解

### 换手缓冲实验

共同评估期2025-02-10至2026-11-03，共436个交易日。以下为同口径公开数据探索结果。

| 配置 | 累计净收益 | 最大回撤 | 累计双边换手 | 日均股票仓位 |
|---|---:|---:|---:|---:|
| 多因子，无缓冲 | 11.32% | 10.19% | 87.29倍 | 77.46% |
| 多因子＋TopK Drop | 11.99% | 10.21% | 29.61倍 | 77.56% |
| 再加执行限额 | 10.70% | 7.90% | 22.73倍 | 66.78% |

换手约下降66%、佣金约下降45%。限额版有9个交易日低于50%股票仓位，集中于初始建仓；其回撤较小部分可能来自更低仓位，不能全部归因于选股改善。没有据本轮结果调整参数。

### 风险矩阵及优化接口实验

共同评估期2025-11-10至2026-11-03，共247个交易日。等权TopK与优化版均为净收益7.85%、最大回撤6.62%、日均仓位77.74%，逐日净值一致。

原因是20只×单股4%恰好等于80%，52次求解都验证为唯一容量解。接口已在有调权空间的合成案例中通过解析解验证，但当前策略没有调权自由度。两段实验起点和账户路径不同，累计收益不可直接相减归因。

本轮目标Beta估计均值约0.331，未达到原完整方案0.85下限。本版并未强制这一约束。历史基准权重与行业版本仍缺失，不能计算或认证完整主动偏离和跟踪误差。

这些结果有当前股票池、最新复权历史、发布时间假设、流动性代理、公司行动保护及成交模型等限制，不是独立样本外、真实成交或稳定盈利证明。

## 四、已有接口与周五应讨论的接口

| 边界 | 已有内部类型／产物 | 外部接入待定事项 |
|---|---|---|
| 行情与日历 | TradingSession、SessionBar、PublicResearchObservation | 来源授权；证券标识；时区和交易时段；实际发布时间；复权及公司行动；迟到与修订 |
| 模型分数 | SignalScore | 代码、信号日、可用时间、分数、明细、不可用原因；本次没有训练ML模型 |
| 账户状态 | AccountSnapshot | 外部现金、持仓、未完成订单和成交如何同步；以哪个账户为准；启动及重启恢复 |
| 组合目标 | TargetWeights | 完整目标权重、信号时间、买入优先级、数据风险及可选预算；接口接收方不能将其误读为增量订单 |
| 拟订单／执行 | 本地orders、trades及rebalances输出 | 待新增外部委托标识、价格和有效期规则、重复提交防护、撤单与部分成交状态机 |
| 成交回写／对账 | 本地现金、股数、费用和公司行动账本 | 待新增外部成交唯一键、费用币种、成交重放、券商与本地余额／持仓差异处理 |

两条已有语义必须保留：完整目标中遗漏的已有股票意味着目标为零；没有目标（None）意味着保持已有持仓。券商对接时不能混淆。

现有回调在批量回测引擎中按日推进，并不等于已经具备持续运行的事件循环、重启状态恢复、网络重连或券商幂等下单能力。

## 五、周五会议建议确认的事项

1. **第一阶段联调目标**：先做本地仿真、前向拟订单记录，还是直接开发券商模拟账户适配器；明确本地演示不代表外部模拟盘已经接通。
2. **行情与历史预热**：选定来源及授权、日线／分钟线口径、实际可用时间、公司行动和更新方式。60日Beta至少61个价格日，252日协方差至少253个价格日；开盘后5–20分钟执行还需要相应行情和成交假设。
3. **账户与订单权威来源**：谁提供现金和真实持仓，成交如何回写，部分成交如何计算下一次目标，启动和重启如何防止重复订单。
4. **执行方式**：券商模拟API／TWS／Gateway方案由团队确认，定义订单类型、执行时点、有效期、撤单、重试、断连和拒单处理。
5. **策略口径**：是否保留80%／20只／4%的等权版本；若要真正优化权重，应另定持股数或上限。95%／85%目标与20只上限冲突，不能同时直接启用。
6. **接口验收分工**：明确数据适配、执行适配、策略与账户对账的负责人员，会议后再给出里程碑与生效版本。

## 六、会后建议的最小验收顺序

| 顺序 | 应交付的证据 |
|---|---|
| A：规范化模拟数据导入 | 同一份数据得到同一信号及目标；日期、单位、复权、时间和缺失处理可核对 |
| B：只记录拟订单的前向运行 | 实际首次获取时间、拟订单和跳过原因留档；重复运行不会重复形成外部动作 |
| C：券商模拟小范围闭环 | 提交、拒单、部分成交、撤单、重连及成交回写能逐笔核对；不使用真实资金账户 |
| D：持续观察 | 账户现金、持仓、费用及未完成订单逐日对账；异常时有明确停止与恢复流程 |

这一顺序是会后实施建议，当前尚未执行B至D，也没有创建定时任务或发起外部交易。
