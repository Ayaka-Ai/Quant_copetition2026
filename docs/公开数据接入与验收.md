2026 年 11 月 4 日，按团队“仅使用无需凭证的公开数据”的选择，完成公开行情读取、两年小样本获取、日历核对和本地缓存验收入口。三只样本标的（AAPL、MSFT 和基准 ETF SPY）的日期及价格字段检查通过，但**冻结的 V1 尚未通过正式数据验收**，不能据此报告策略收益。交易规则、20 日窗口、流动性门槛和信号截止时间均保持原样。

## 运行方式与输出

在仓库根目录运行，Python 3.8+，数据解析和离线检查无需额外依赖。联网获取时需要可用的 HTTPS 证书库；若系统 Python 的证书库不可用，可使用具备 `certifi` 的 Python 环境，不关闭证书校验。

```bash
# 只读取本地缓存，不联网
python3 -m examples.prepare_public_data

# 下载固定三只股票的两年公开试样；已有完整缓存时复用
python3 -m examples.prepare_public_data --fetch-public-pilot

# 检查交易日历、数据异常、可用时间和原有策略模块
python3 -m unittest discover -s tests -v
```

请求仅访问无需凭证的 Yahoo chart 历史接口，不使用行情收费接口。三只标的逐只请求，每次最多三次传输尝试；认证或限流错误立即停止该次获取，不切换身份或绕过限制。中断后保留已成功下载的文件，可继续同一固定请求。公开接口没有本项目所需的稳定性承诺，失败会写入报告并以非零状态退出。

| 文件 | 用途 |
|---|---|
| `outputs/data_acceptance/data_acceptance.json` | 总验收状态、逐股日期缺口、价格空值、来源能力缺口、哈希和本次开支为零的记录 |
| `outputs/data_acceptance/public_daily.csv` | 1,503 条标准化公开记录，保留 `yahoo_*` 字段名 |
| `outputs/data_acceptance/corporate_events.json` | 提供方公司行动原始字段；公告时间和支付日期留空 |
| `outputs/data_acceptance/exchange_calendar.csv` | 独立于价格样本的完整交易日程及 UTC 开收盘时间 |
| `outputs/data_acceptance/public_raw/manifest.json` | 本次试样原始响应版本、下载时间和哈希 |

导出文件的 SHA256 也写入验收报告。只有哈希与本次有效报告对应的导出文件才属于该次结果；目录里可能留有之前运行的文件。`outputs/` 保持本地忽略，不将原始行情纳入代码版本库。

## 输入边界

`quant_data/public_daily.py` 校验响应中的代码、美元货币、纽约时区和日频元信息，以及有序唯一时间戳、列长度、OHLC、成交量和公司行动字段。空值原样保留，缺失日期按独立日历报告；损坏缓存、错误响应、未收盘交易日及哈希变化直接拒绝。

`quant_data/us_calendar.py` 根据交易所公告维护 **2024—2026 年**的有限日历，包括 2025-01-09 临时休市和提前收盘日。UTC 时间按这三年的夏令时边界转换；超出年份范围报错，不用简单周一至周五外推。日历只提供计划开收盘时间，不推断数据发布时间。[NYSE 节假日与提前收市公告](https://ir.theice.com/press/news-details/2023/NYSE-Group-Announces-2024-2025-and-2026-Holiday-and-Early-Closings-Calendar/default.aspx)、[2025 年临时休市公告](https://ir.theice.com/press/news-details/2024/The-New-York-Stock-Exchange-Will-Close-Markets-on-January-9-to-Honor-the-Passing-of-Former-President-Jimmy-Carter-on-National-Day-of-Mourning/default.aspx)。

公开价格只以来源字段名保存。`yahoo_adjusted_close` 用于探索性收益计算；Yahoo 说明该字段包含拆股与分配调整，但当前返回的历史版本不能证明当时已知的复权信息。[Yahoo 复权价格说明](https://in.help.yahoo.com/kb/adjusted-close-sln28256.html)。`yahoo_open/close` 没有改名为实际历史股数口径的未复权价格。

`public_observations` 可把有效缓存转换为现有 `MomentumObservation`：可用时间统一采用该响应的真实下载时间，未复权价格、精确成交额、交易权限和公司行动清算状态全部留空。较早的信号时点看不到今天才取得的数据；历史研究必须另有当时版本或明确采用新的研究假设。

## V1 尚缺的输入

| 要求 | 当前公开响应 | 处理 |
|---|---|---|
| 常规时段开收盘口径 | 日期和时间戳可与日历对应，但具体成交条件及聚合范围未独立核实 | 对应准备状态保持 `false` |
| 信号时点已知的复权序列 | 只有当前版本及事件日期，无历史修订和公告记录 | 不追溯宣称符合当时可见性 |
| 实际股数口径的未复权价格 | 不能将可能按拆股调整的 OHLC 直接当作历史账本价格 | 未复权价格保持空值 |
| 30 日全市场常规时段精确美元成交额 | 只有每日成交量；没有逐笔美元总额 | 不使用 `close × volume` 充当精确成交额 |
| 收盘后 30 分钟内可用 | 记录了今天的下载时间，历史发布时间未知 | 不把交易所收盘时间写成行情发布时间 |

五项 `DataReadiness` 均保持 `false`。字段及日期检查通过只表示试样结构完整。接入现有目标生成器仍产生 `data_not_ready` 和零个目标事件，不会生成空权重导致清仓。账户的分红与拆股事件记账也尚未实现，24 条分红记录不能直接当作支付日现金流水。

三只标的不足以代表完整标普股票池，因此先验证来源能力，暂不批量获取 503 只两年数据。扩展同类响应不会补出其中没有的成交额或发布时间。

## 验证记录

本次全部 70 项测试通过，其中 12 项新增测试覆盖：临时休市、夏令时、提前收市、完整交易年数量、日期缺口、空值、不合法 OHLC 和成交量、错误响应、下载时间不回填、缓存篡改及公开数据状态阻止目标生成。原有 58 项账户、动量和约束测试继续通过。

另在 Python 3.12 中使用 `zoneinfo` 独立核对全部 501 个交易日的纽约本地开收盘时间，并重算三只标的截至 2026-11-02 的 20 日收益，与此前排名缓存一致（绝对差小于 `1e-6`）。结果和导出哈希保存在 `outputs/data_acceptance/independent_crosschecks.json`。Python 3.8 与 3.12 均通过全部测试。
