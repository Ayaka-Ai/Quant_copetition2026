## 公司行动核查

29 条来源 `splits` 记录涉及 27 个代码，全部保留来源事件标识、日期、原始比例及字段。10 个代码含既非整数、也非整数倒数的比例：BDX、CMCSA、DD、FDX、FTV、HON、J、LEN、SPGI、WDC。这只是优先核查标记，普通比例也不自动视为已核实的真实拆股。

已核对两个公开披露案例，说明事件类型与股数处理必须分开：

- WDC 在来源清单中于 2025-02-24 记有 `1323:1000`。Sandisk 的公告说明当日完成从 Western Digital 的分离并开始独立交易，不能仅据来源比例就增加 WDC 持仓股数。[Sandisk 公告](https://www.sec.gov/Archives/edgar/data/2023554/000119312525033433/d849281dex991.htm)。
- FTV 在来源清单中于 2025-06-30 记有 `1327:1000`。公司公告说明 Ralliant 分拆于 2025-06-28 完成，原股东每三股 FTV 获一股 Ralliant；不是把 FTV 股数机械乘以 1.327。[Fortive 公告](https://www.sec.gov/Archives/edgar/data/1659166/000165916625000104/ex991-pressrelease.htm)。

上面是来源记录与已披露公司行动的对照，不是对全部 Yahoo 调整因子计算方式的核实。事件均标记 `legal_action_type_verified: false`，真实股数变更和价格基准仍需逐事件归类；不能把 `splits` 字段整体直接送入账户。

所有分红记录的每股金额基准和真实支付日期仍未确证，标准化字段保持空值。公开版后续采用除息日现金代理，也需要先确认对应的持有资格和每股金额基准。简单检查未发现没有对应现金分配事件的复权比率突变，但这不能证明不存在漏报、修订、分拆或重复调整。

## 运行与文件

在仓库根目录运行，下载和离线验收支持 Python 3.8+。联网需要有效 HTTPS 证书库，可用安装了 `certifi` 的 Python 环境；不关闭证书校验。

```bash
# 首次获取，或仅补尚未请求的代码；已经保存的响应不重取
python3 -m examples.prepare_public_universe --fetch

# 仅重新检查本地文件，不联网
python3 -m examples.prepare_public_universe

# 独立逐条核对原始响应与导出、时区；需 Python 3.9+
python3 -m examples.check_public_universe

# 回归测试
python3 -m unittest discover -s tests -q
```

固定输出目录为 `outputs/public_universe_20261104/`，约 110 MB。目录受 `.gitignore` 保护，原始行情及派生数据留在本地。

| 文件 | 内容 |
|---|---|
| `raw/manifest.json` | 全部 504 个代码的请求、状态、实际下载时间、重试记录和原始文件哈希 |
| `raw/*.json` | 原始响应，包括 KVUE 异常响应 |
| `public_daily.csv` | 标准化日线及公开版流动性代理；实际未复权价格和历史发布时间留空 |
| `inventory.csv` | 可筛选的逐股覆盖、行业、发行人、窗口、空值及异常清单 |
| `inventory.json` | 完整逐股审计，含首日前、末日后和内部缺口的分类 |
| `corporate_events.json` | 全部 3,215 条来源事件及事件基准、合法类型待核实标记 |
| `exchange_calendar.csv` | 本区间独立交易日历、UTC 开收盘时间 |
| `summary.json` | 获取完整度、异常、来源局限、数据哈希及回测未启用状态 |
| `independent_crosschecks.json` | 原始响应对照及纽约时区独立复核记录 |

每批最多两个并行请求，批间暂停；临时传输或服务端错误最多三次尝试。遇到 401、403 或 429，停止发起后续批次并保留状态，不切换身份或绕过限制。本次未遇到这些阻断。再次运行会检查全部已保存响应的哈希、股票池和配置指纹；跨调整基准日不得向旧目录混入新批次。
