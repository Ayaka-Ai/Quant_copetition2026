## 规则及冲突处理

新增独立配置 `configs/risk_preflight_v1.json`，以哈希引用原TopK配置。基准按100%股票指数的净资产权重定义，不随策略仓位缩放；现金Beta为零。

| 项目 | 本次检查口径 |
|---|---|
| 单股绝对上限 | NAV的4% |
| 行业绝对上限 | NAV的20% |
| 单股主动偏离 | 相对完整基准±1.5% NAV |
| 行业主动偏离 | 相对完整基准±3% NAV |
| Beta区间 | 组合净资产口径0.85–1.05，现金Beta为零 |
| 预测年化跟踪误差 | 相对完整基准不超过8%；日收益协方差按252年化 |
| 持股数 | 当前研究实现最多20只；不是对原完整方案持股数的替代规定 |
| 目标仓位 | 当前研究80%；检查提议状态95%、85%、60%，不直接启用 |

处理顺序已明确：

1. 数据可用性、来源、计量单位和有效期先验收，缺失不视作零。
2. 所有硬约束须同时满足，不通过优先级暗中放宽任何上限。
3. 必要条件已证明无解时，不生成新的优化目标，保留原持仓并输出原因；已有持仓不因此被保证满足新风险规则。
4. 风险减仓作为单独核验的订单路径处理，仍受执行金额限额约束。未完成减仓须保留告警，不能自行绕过预算。
5. 初始建仓、普通调仓和风险减仓均沿用单日双边成交金额25%限制，没有初始建仓豁免。公司行动和佣金不计入普通成交金额预算。
6. 低仓位只记录和诊断，不强制买入，也不据研究统计自行判断官方比赛资格。

这些是本轮离线验收约定。新配置未接入原策略的交易路径，既有版本保持原样。

## 已发现的确定冲突

| 配置组合 | 必要条件结论 |
|---|---|
| 最多20只、每只不超过4%，目标95% | 上限80%，无解；95%至少需要24只 |
| 最多20只、每只不超过4%，目标85% | 上限80%，无解；85%至少需要22只 |
| 同样限制，目标80% | 单凭持股数和上限不能否决；还需历史权重、行业、Beta和协方差 |
| 同样限制，目标60% | 持股数下界15只；完整风险约束仍待数据检查 |

其他已经实现并用合成案例验证的无解检查：

- 基准中某股8%，允许低配1.5%，则最低持有6.5%，超过4%绝对上限。这里8%是说明用例，不是本次对历史指数权重的观测。
- 某行业基准权重超过23%时，行业低配不超过3%与绝对上限20%可能直接冲突。
- 所有单股／行业最低权重之和高于目标股票仓位时无解；所有最高权重之和低于目标仓位时也无解。
- 由基准低配限制强制持有的股票数超过20时无解。
- 在完整已知股票池Beta范围下，即使放松其他分配限制，目标仓位仍无法达到组合Beta区间，则原问题也无解。

60%仓位要达到组合Beta下限0.85，股票部分的加权平均Beta至少约1.4167；这与低波防御方向可能不一致。不能据此断言所有60%组合无解，仍需完整股票池Beta和约束数据。

## 输入契约与验收实现

新增 `quant_data/risk_inputs.py`。输入目录默认 `risk_inputs/`，其中 `manifest.json` 使用 `risk_inputs_v1` schema，按 `kind` 登记JSON文件及SHA256。模板为 `configs/risk_input_manifest.example.json`，空模板不会被当作已准备好。

每个JSON文件是记录列表，记录至少包含：

| 字段 | 要求 |
|---|---|
| `as_of` | 数据适用交易日或行业生效日期 |
| `available_at` | 带时区的真实可用时间；不能用现在取得时间倒填过去可用性 |
| `source` | 可追溯来源标识；字段存在不等于来源已获独立核实 |
| `units` | 权重 `NAV_fraction`；行业 `GICS_sector`；Beta `dimensionless_SPY_beta`；协方差 `daily_return_covariance` |
| `payload` | 权重／行业／Beta按代码映射；协方差为 `symbols` 和同顺序的 `matrix` |
| `valid_through` | 行业版本必须声明有效期结束日 |
| `estimation_start/end` | Beta及协方差必须声明估计价格窗口 |

权重、Beta、协方差要求适用日与信号日一致，不自动以前一日填补；行业只可在有效期内沿用。所有版本还须满足 `available_at <= 信号截止时间`。估计结果不能早于最后输入交易日收盘，重复且含糊的版本会拒绝。

数据齐全时，进一步检查完整候选池加基准成分的行业、Beta、协方差覆盖；Beta至少61个交易价格日，协方差至少253个；权重和为1，Beta有限；矩阵须方阵、有限、对称、半正定且单位正确。不修复负特征方向，不用单个组合的正方差代替整张矩阵检查。

半正定检查采用支持零主元的分解，容差为1e-18，允许奇异半正定矩阵。数百只股票、252日样本形成的协方差可能奇异，即便PSD通过也不保证优化稳定；收缩估计、条件数和模型质量仍需后续实现与验收。

## 建仓路径复核

限额变体在436个评估交易日中，有9日股票仓位低于50%，日期是：2025-02-10至02-14、02-18至02-21。均位于起始建仓阶段；前20日真实现金、净值和仓位保存在 `entry_path.csv`。

在净值不变、无卖出、费用及取整损耗的理想情况下，每次25%双边成交预算建立80%仓位也至少需要4次执行机会。周度调仓可能延长低仓位阶段，实际价格及订单行为会影响路径，不能把这个下界当作成交承诺。

本次保留“首次建仓不豁免”的既有研究规则，没有为满足仓位指标而事后更改结果。后续若比较每日分批建仓、建仓单独预算或其他安排，应创建新配置并预先记录规则；不能混入普通调仓规则。
