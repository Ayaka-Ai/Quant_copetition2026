## 3. 第一个例子：从行情到首次建仓

## 4. 第二个例子：读取实际持仓后换仓

11月14日策略读到实际持有的20只及其股数，而非上周目标。常规替换最多 floor(20×20%)=4只，分数优势至少0.15×当日分数标准差，即0.034890。本次没有强制资格退出或空位补入，发生以下4组替换：

| 卖出标的 | 买入标的 | 分数优势 | 当日门槛 |
|---|---|---|---|
| HCA | AMGN | 0.491999 | 0.034890 |
| SLB | VTR | 0.447192 | 0.034890 |
| KLAC | RTX | 0.344777 | 0.034890 |
| LRCX | GD | 0.189700 | 0.034890 |

同一完整目标还会调整保留股票的股数，因此不是只有8笔订单：本次共15笔（8买、7卖），11月17日按先卖后买全部模拟成交。PLD继续保留，并从31股加至32股；其最终入选来自TopK缓冲，不是当日无缓冲前20名。

现金核对：22,228.970562 + 公司行动现金5.70 + 买卖净现金变化(-44.042309) = 22,190.628252美元。公司行动采用研究用除息日现金口径。

11月17日收盘市值76,281.29美元，权益98,471.92美元，实际股票仓位77.47%。11月14日目标预测波动13.60%、Beta 0.5175；优化器仍返回唯一容量解。

完整目标中遗漏已有股票表示目标降至零；没有新目标（None）表示保持实际持仓。缺风险版本、风险覆盖不足或求解失败时，适配层不生成新目标并记录原因。

## 6. 怎样重新跑

先按 README 创建环境并安装依赖，再从仓库根目录执行；需已有完整缓存，无需联网：

```bash
OPENBLAS_NUM_THREADS=1 python -m examples.run_interface_demo --output outputs/interface_demo_20261112
```

该入口先执行原风险回放，再导出两次决策追踪。若已完成回放，只补导出追踪可追加 `--inspect-only`。要保留本次文件，可把 `--output` 改为新的空目录。

本次实际依次执行原回放命令与演示入口的 `--inspect-only`，不是把旧结果直接当成本次运行；核验文件保留本次配置、代码及输出指纹。PDF构建脚本为 `tmp/pdfs/build_interface_demo_report.py`，报告中的数字读取本次结果。
