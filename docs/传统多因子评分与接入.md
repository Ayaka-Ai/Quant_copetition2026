# 传统多因子评分与接入

2026-11-07 完成第二步：新增传统多因子评分和通用分数接口，在本地公开数据上与共同股票池的20日动量比较。本版为 `FACTORS-PUBLIC-1.0.0`，不包含机器学习、新闻、市场状态或TopK Drop。

## 运行

在仓库根目录执行：

```bash
python3 -m examples.run_public_multifactor
python3 -m unittest discover -s tests -q
```

Python 3.8+，无新增依赖，不联网、不下载、不连接券商。默认使用已有 `outputs/public_universe_20261104/` 缓存，输出至 `outputs/public_multifactor_20261107/`。支持 `--input`、`--output`。已有结果目录会校验首次登记的配置哈希，不覆盖其他配置的实验。

本轮固定配置为 `configs/multifactor_public_v1.json`，通过哈希引用第一步 `momentum_public_backtest_v1.json`。因子公式及权重在首次多因子收益计算前写入配置，未根据本轮结果修改或搜索参数。

## 代码和接口

| 文件 | 作用 |
|---|---|
| `quant_signals/scores.py` | `SignalScore`：代码、信号日期、可用时间、Decimal分数、分解明细和不可用原因 |
| `quant_signals/multifactor.py` | 原始因子、行业内去极值和标准化、组合评分、相同完整因子池的动量评分 |
| `quant_data/public_research.py` | 增加仅用于因子的调整后开高低价；账户价格和股数口径仍独立 |
| `quant_portfolio/public_momentum.py` | 原入口新增可选 `score_provider`、策略ID、最短信号历史参数；资格和风险约束共用 |
| `examples/run_public_multifactor.py` | 四组合共同区间回测、账目核对、归因明细和报告 |

评分提供者接收 `(signal_session, cutoff, eligible_candidates)`，必须对每个资格合格的候选返回一个 `SignalScore`。不可用时返回 `value=None` 并给出原因，组合层将其排除；不能静默改用动量或用零分替代未知。股票、信号日不符或可用时间晚于截止的分数会被拒绝。数据导致全池无法评分时不生成清仓目标。

不传 `score_provider` 时继续使用原20日动量路径。原入口全部104条周度决定与第一步保存结果逐字段一致，包括候选、原因、排序及目标；证据见输出目录的 `momentum_compatibility.json`。

## 原始因子定义

令 `C` 为同一冻结版本的复权收盘价，`O/H/L` 为来源OHLC乘当日 `AdjClose / Close`，`A` 为来源 `Close × Volume` 流动性代理。调整后的OHLC只参与因子，不用于成交和账户估值。跳空因此采用总回报调整口径，不是未复权报价跳空。

所有股票均要求连续61个交易日的可用、公司行动基准清楚的收盘历史，另外要求对应OHLC和流动性数据。窗口按交易日历定位，缺日不压缩、不填补；因子缺失不对剩余权重重归一化。

| 组 | 原始因子及方向 |
|---|---|
| 趋势 | `C/C[-5]-1`、`C/C[-20]-1`、`C/C[-60]-1`；相对最近20、60个收盘价均值的偏离 |
| 反转 | `1-C/C[-1]`、`1-C/C[-3]` |
| 日内质量 | `(C-L)/(H-L)`，平价日中性0.5，舍入后限制在[0,1] |
| 量能确认 | 20日动量乘 `A/Mean(A,20)` |
| 低波 | 最近20日收益总体标准差、下行半偏差、最近5日绝对跳空均值，均取负向 |
| 流动性稳定性 | `ln(Mean(A,20))`、负向的20日成交额代理变异系数 |

下行半偏差为 `sqrt(mean(min(r,0)^2))`，分母包括所有20个收益日；流动性变异系数为总体标准差除均值。低波组同时考虑历史波动与跳空；流动性组同时考虑规模与稳定性。共14个原始因子。

## 标准化和合成

仅对当日通过价格、流动性、行业、发行人及完整因子检查的候选，按现有冻结GICS行业大类分组：

1. 每个原始因子按行业中位数上下3倍MAD截尾，MAD为零时不截尾。
2. 截尾后按总体标准差计算z分数；零方差或单成员组记为0。
3. 每个组内的原始因子z分数等权平均，得到六组分数。
4. 合成价量和防御分数后，在整个完整合格池内取分位；并列采用平均排名，单成员及全体同分均为0.5。

```text
PriceVolume = 0.45 × Trend + 0.25 × Reversal
            + 0.20 × IntradayQuality + 0.10 × VolumeConfirmation

Defensive = 0.60 × LowVolatility + 0.40 × LiquidityStability

Score = (0.25 × Percentile(PriceVolume)
       + 0.10 × Percentile(Defensive)) / 0.35
```

这保留文档中价量与防御的25:10比例。尚未实现的ML分数权重0.65被移除，不伪造预测，也不把本版称为完整CLEAR-US。

## 公平比较和交易规则

四个组合共用信号日期和评估起点：

- 多因子：按新分数选股。
- 动量对照：在完全相同的61日完整因子候选池内，按20日动量选股。
- 80% SPY加现金。
- 共同完整合格池目标80%等权，不叠加选股的行业及发行人限制。

多因子与动量均最多20只、每只4%、行业上限20%、同发行人最多一个股类，选不满留现金；同分按代码排序。共用10万美元、整数股、简化佣金、单边5 bps滑点、下一交易日开盘代理及公司行动账本。

由于新增60日收益，需61日预热，第一笔共同成交为2025-02-10。不能直接把本轮累计收益与第一步2024-12-23起的结果相减。程序还检查两次评分路径生成的SPY与等权基准目标完全一致。

## 首轮结果

评估期2025-02-10至2026-11-03，共436个交易日；共13个预热周、91个有效信号周。

| 组合 | 累计净收益 | 年化夏普 | 最大回撤 | 日均实际股票仓位 | 双边累计换手 |
|---|---:|---:|---:|---:|---:|
| 传统多因子 | 11.32% | 0.633 | 10.19% | 77.46% | 87.29倍 |
| 共同池20日动量 | 68.72% | 1.707 | 17.55% | 78.26% | 70.46倍 |
| 80% SPY加现金 | 21.51% | 0.900 | 15.15% | 79.75% | 1.00倍 |
| 共同池目标80%等权 | 10.82% | 0.953 | 7.24% | 37.82% | 2.44倍 |

这组固定多因子全期收益和夏普低于动量及SPY，但最大回撤小于两者；其双边换手高于动量，仍有换手缓冲的工程研究空间。不能把增加因子直接等同于策略改进。

沿用第一步预先固定的描述性区间：较早区间多因子5.64%、动量69.63%；2026-05-04至2026-11-03后段，多因子5.38%、动量-0.54%。后段相对改善不足以证明整体更优，这两段都不是独立样本外，本次未据此改权重。

等权实际仓位仅37.82%，仍受10万美元分散到数百只股票时的整数股与最低佣金影响，不能视为同风险敞口的组合。所有净收益已经扣费，滑点包含于成交价，不再次扣减。

沿用第一步的当前股票池选择／幸存者偏差、最新复权历史、模型发布时间假设、成交额代理、复杂公司行动的未来已知历史保护区间，以及除息日提前税前现金记账等局限；完整列表见生成报告。

## 输出和验证

输出包含 `report.md`、`comparison.json`、`net_values.csv`、配置及运行登记、全池分数和原始因子 `decisions.json`、行业标准化统计 `normalization.json`、共同池动量决定和四组合完整账目。

127项测试通过，新增覆盖因子窗口、缺日及公司行动保护、调整价与实际股数口径隔离、MAD、零方差、并列分位、通用评分影响选股、拒绝未来分数、共同池对照及未来行情隔离。所有组合通过每日现金、股数、净值和次日成交检查。
