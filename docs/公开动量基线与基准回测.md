## 运行

在仓库根目录执行，Python 3.8+，无新增依赖：

```bash
python3 -m examples.run_public_momentum
python3 -m unittest discover -s tests -q
```

脚本只读本地响应，不联网、不下载、不连接券商。可用 `--input` 指定完整缓存目录、`--output` 指定结果目录。默认输出为 `outputs/public_momentum_20261107/`。重跑检查原登记配置，保留首次 `run_protocol.json`；若配置变化，应使用新的输出目录。

新配置是 `configs/momentum_public_backtest_v1.json`。原 `momentum_public_v1.json`、严格 V1 及原数据清单不覆盖；新配置以哈希引用原公开配置，经济规则逐项一致，只增加执行状态、实验窗口和记录。严格 V1 加载器继续拒绝公开配置，五项 `DataReadiness` 不修改。

| 模块 | 职责 |

| `quant_data/public_research.py` | 校验原配置、股票池、响应和已核查事件哈希；从原始响应重建价格及事件；分别保留模型时间与真实下载时间 |

| `quant_backtest/research_metrics.py` | 统一评估期的净收益、夏普、回撤、换手、仓位、费用和周正收益比例 |

公开适配器未把 `close × volume` 放入严格接口的精确成交额字段。模型可用时间为收盘后30分钟假设，实际获取时间单列；复权历史固定为同一缓存版本。拆股后实际股数价格及税前分配沿用已有 `prepare_action_basis` 和账户规则。

股票池仍保留503个代码，SPY单独作基准。KVUE的日线契约失败、历史不足、复杂行动保护区间及其他缺失均保留在逐股审计中，不删除原股票池成员。复杂行动沿用既有的快照范围历史保护策略：这会使用后来已知事件排除更早候选，必须与其他回看偏差一起披露，不是无未来信息的严格回测。

## 统一交易与评估口径

- 动量：完整21个交易日复权收盘价计算20日收益，30日完整流动性代理窗口。
- 策略：每周最后交易日收盘后30分钟排序；最多20只、每只4%，行业不超过20%，同发行人最多一个股类；选不满留现金。
- 基准：80% SPY加现金；同一合格池目标80%等权，等权基准不套用行业及发行人选股上限。
- 三者共用计划信号日期、下一交易日开盘代理、公司行动、初始10万美元、整数股、佣金和5 bps单边滑点。SPY信号数据不齐则三者一起跳过。
- 数据不足不生成清仓目标；持仓价格或公司行动不明仍由账户阻塞调仓及有效绩效，不能丢掉无效日期后计算完整收益。
- 评估从首个共同目标的下一交易日开始，预热不计收益。期末按收盘估值，不强制平仓。
- 净收益已扣佣金及成交价内滑点；滑点归因不得二次扣减。夏普采用净日收益、252日年化、零无风险利率及样本标准差；零波动报告不可计算。
- 双边换手为当日买卖成交金额合计除以前日净值。周正收益比例按自然周复合日收益，包含首尾部分周。

配置在首次完整策略运行前固定描述性子区间：2024-11-04至2026-05-04，以及2026-05-04至2026-11-04，右端不含；与实际评估期取交集。本次没有参数搜索，两段均不宣称独立样本外。

## 本轮结果

实际评估日期为2024-12-23至2026-11-03，共467个交易日。

| 组合 | 累计净收益 | 年化夏普 | 最大回撤 | 日均实际股票仓位 | 佣金 |
|---|---:|---:|---:|---:|---:|
| 20日动量、20只、目标80% | 72.87% | 1.626 | 17.92% | 78.22% | $2,660.46 |
| 80% SPY加现金 | 23.75% | 0.927 | 15.14% | 79.73% | $36.00 |
| 合格池目标80%等权 | 12.37% | 1.017 | 7.30% | 38.14% | $3,247.00 |

动量相对SPY的累计净收益差为49.12个百分点，但最大回撤更大；这只是此探索区间和数据假设下的结果，不是风险调整后的alpha，也不是稳定有效性证明。

等权组合需要把约80,000美元分散到数百只股票。整数股向下取整使很多股票无法达到目标，最低佣金进一步造成成本，因此实际仓位明显不足。其较低回撤不能直接解释为策略更优，也不能把它当作与动量组合风险敞口相近的基准。保留这一诊断结果，不静默切换到碎股、增加资金或减少股票数；这些变化应另建实验配置。
