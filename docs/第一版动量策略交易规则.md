# 第一版动量策略交易规则

策略编号：US_MOM20_EW。规则版本：1.0.0。冻结日期：2026 年 11 月 3 日，香港时间。

本版固定为美股多头的 20 日动量选股与等权配置策略，用于下一阶段实现和研究回测。核心假设是近期相对强势可能延续，是否有效由独立实验判断。机器可读参数见 [momentum_v1.json](../configs/momentum_v1.json)。2026 年 11 月 4 日已完成 [组合账户基础接口](组合账户接口.md)与 [动量选股及周度目标生成](动量选股与周度目标.md)。实际数据验收和公司行动记账仍待完成，券商下单保持关闭。

## 核心规则

| 项目 | 固定规则 |
|---|---|
| 股票池 | 2026 年 11 月 3 日取得的标普 500 成分股快照，共 503 个证券代码、500 个发行人；本版固定名单，逐次检查交易资格 |
| 市场与方向 | 美国上市、美元交易普通股，包括 REIT 普通股；只做多、整数股、不借贷 |
| 动量 | `MOM20(t) = AdjClose(t) / AdjClose(t−20) − 1`，20 个收益区间需要 21 个交易日收盘价 |
| 排序 | 未四舍五入的动量降序；完全相同时按证券代码 ASCII 升序 |
| 调仓频率 | 每个周一至周日自然周内最后一个美股交易日生成信号，下一交易日执行 |
| 信号截止 | 信号日常规时段收盘后 30 分钟；提前收市日相应提前，全部使用 America/New_York 时区 |
| 持仓数量 | 最多 20 只；不要求动量必须为正 |
| 单股目标 | 每只入选股票占信号时点净资产 4% |
| 行业目标 | 每个 GICS 一级行业最多占信号时点净资产 20%，对应最多 5 只 |
| 同公司股类 | 每个发行人最多持有一个股类；扫描时优先选择排名更高且合格的股类 |
| 总股票目标 | 选满 20 只时为 80%，剩余 20% 为现金；选不满时每只仍为 4%，其余留现金 |
| 退出 | 周度调仓时未入选股票目标为零；仍入选的股票也恢复至 4% 目标权重 |
| 价格止损止盈 | 本版不另设价格止损、止盈或市场状态降仓条件；普通买卖由周度目标驱动 |
| 研究成交 | 下一交易日常规时段开盘价，加减单边 5 bps 滑点，作为研究成交代理 |

目标限额按信号时点计算。整数股、费用、开盘跳空、未成交及之后的价格变化会造成实际权重偏离，每日记录敞口，在下一次计划调仓恢复目标。4% 和 20% 不代表盘中或持有期间持续有效的硬限额。

## 股票资格与数据要求

每次信号使用截止时已知的信息，逐一检查：

1. 股票在冻结名单内，行业和发行人 CIK 已知，当前仍上市且可交易，并满足拟用账户的交易权限。
2. 信号日实际股数口径的未复权常规时段收盘价不低于 5 美元。
3. 截至信号日的最近 30 个交易日，美元成交额算术平均值不低于 2,000 万美元。30 条记录全部有效，成交额覆盖全市场常规时段交易，定义为各笔成交价格乘股数之和。
4. 20 日动量所需的 21 个收盘价全部有效、日期与交易日历一致；复权包含拆股和现金分红，并且相应事件在信号时点已可获知。
5. 数据没有未处理的异常、重复、停牌状态或公司行动。候选股票缺少所需数据时排除并记下原因，不前向填充。

单交易场所成交量、组成场所成交量及 `close × volume` 不能直接替代本版要求的美元成交额。若数据集整体无法满足时段、可用时间、复权或成交额口径，运行结果应为“数据未准备好”，而不是将整池当成零只合格股票并清仓。

快照保存在 [sp500_2026-11-03.json](../configs/universe/sp500_2026-11-03.json)，含原始名单来源、哈希、行业和发行人标识。本版不因后续表现临时增加或删减名单；停牌、并购及退市按实际生效时间影响交易资格。使用这份当前名单回测更早历史，只能标为存在选择与幸存者偏差的探索结果。

新闻和队员观点保存为研究备注，不直接改变本版目标持仓。

## 每周选股算法

在合格股票中按动量排序，从第一名开始依次扫描：

1. 若该发行人已有股票入选，跳过该股类。
2. 若该行业已选满 5 只，跳过该股票。
3. 否则入选，赋予 4% 目标权重。
4. 选满 20 只或扫描完全部候选后结束。

若只选到 17 只，总股票目标就是 68%，现金目标 32%。剩余权重不重新分摊。仅在数据已验收、候选条件确实全部不满足时，零只合格股票才对应零股票目标；此情况同时记录持仓资格风险。

首次建仓也遵守周度日程：在激活策略且数据准备完成后的第一个计划信号日计算，再于下一交易日执行。11 月 2 日的排名快照只作为已有研究输入，不据此在非计划时点补交易。

## 从目标权重到模拟订单

信号截止时，用当时已知的未复权收盘价估值整个组合，记为 `NAV_t`。现金、股数及公司行动必须能对账。

对入选股票：

```text
目标股数 = floor(0.04 × NAV_t / 信号日未复权收盘价)
计划买卖股数 = 目标股数 − 当前持仓股数
```

对未入选持仓，目标股数为零。因股价上涨或下跌仍在榜内的股票也会按差额买卖。小于一股的差额不交易。

订单股数在信号时决定，不预先利用下一交易日开盘价反推购买数量。执行日先按证券代码升序处理卖单，再按动量排名顺序处理买单，使用共同资金账户。买单成交时，若现金不足支付股数与佣金，只缩减到可负担的最大整数股，剩余取消；价格下降时也不追加原订单之外的数量。现金和股数均不得为负。

每笔订单只在紧邻的下一交易日开盘尝试一次。若缺少该时点价格、停牌或权限失效，取消受影响订单并记录原因；不得顺延到后来某根有价格的行情冒充原计划成交。下一次普通交易机会是下一周重新形成的调仓计划。

信号与执行之间发生已核实的拆股时，按事件机械调整现有股数和待执行股数；碎股及其他无法准确计量的公司行动须先处理清楚。实际开盘成交及券商可用资金另行验证，本版代理价格不保证能够真实成交。

## 费用与账户记账

| 项目 | 固定研究假设 |
|---|---|
| 初始研究资金 | 100,000 美元；同一次比较中的所有方案一致 |
| 买入成交价 | `下一交易日常规时段 open × 1.0005` |
| 卖出成交价 | `下一交易日常规时段 open × 0.9995` |
| 非零成交佣金 | 每笔 `max(1 美元, 成交股数 × 0.005 美元)`；零成交不收佣金 |
| 滑点处理 | 已计入成交价，成本归因列不再重复扣款 |
| 分红与拆股 | 按已核实事件和生效日期记录现金、应收项目或股数变化，不与信号复权重复入账 |
| 现金利息 | 暂设为零 |
| 分红税与其他费用 | 分红按税前总额；暂不建模预提税、监管费、完整券商佣金上限及市场冲击 |
| 卖出资金可用性 | 研究中假设卖出净收入即时可用；券商模拟执行另按账户实际可用资金和结算规则处理 |

每股 0.005 美元、每笔最低 1 美元是简化研究模型，参考 IBKR 公开费率量级，不代表已核实某个参赛账户的完整收费。压力测试可另用 10、20 bps 滑点作为独立实验，不覆盖本版 5 bps 主配置。

信号复权价只用于计算动量。成交、持仓股数、净值和分红使用一致的实际股数及未复权价格口径。供应商名为 `Close` 的字段不自动等于可用于此账目的未复权价格，须核实拆股处理。

## 异常与持仓监测

- 信号截止时仍缺少组合净值所需的持仓价格，或持仓公司行动尚未处理：取消本周普通调仓，保留持仓并报告异常；不在数据迟到后临时补调仓。
- 单个非持仓候选的数据不齐：按资格规则排除，继续扫描其他候选。
- 市场停牌或订单未成交：保留实际现金和股数，不伪造成交，也不自动新增替代订单。
- 估值价格缺失：可另存带标记的最近可得估值，但该日不得作为有效绩效观测值，不把停滞净值算作零波动。
- 每日输出实际总股票仓位、行业与发行人敞口、现金、未成交和数据异常。低仓位或空仓情况按赛事正式口径复核，不为凑持仓比例突破本版条件。

## 基准和版本管理

使用相同调仓日期、初始资金、成交代理、费用、分红及现金收益口径，比较 80% SPY 加 20% 现金，以及同一合格股票池的 80% 等权配置。第二个基准分配到全部合格证券，不套用动量组合的行业和股类选择限制，以区分股票池本身与完整选择规则的贡献。

每次运行保存规则版本、配置及股票池哈希、数据范围、数据可用时间、价格口径、订单、成交和净值。实验日期属于运行清单，必须在查看该次结果前登记；已用于选择规则的区间不再称为独立样本外。

本说明与配置共同作为 V1 实现依据。参数、股票池、时间规则或jie费用主假设变化时，新建版本并记录生效时间，不覆盖既有结果。旧 CLEAR-US 草稿保留为其他研究构想。

当前已有榜单尚未验证 30 日全市场成交额和账户所需未复权价格；现有 Databento UTC 日柱也不能替代本版常规时段开盘成交价。旧“下一根 UTC 日柱 close”示例保留为工程演示，不与本版回测混用。

交易日及提前收市依据 [NYSE 日历与交易时段](https://www.nyse.com/trade/hours-calendars)；费用参考 [IBKR 美股佣金说明](https://www.interactivebrokers.com/en/pricing/commissions-stocks.php)。
