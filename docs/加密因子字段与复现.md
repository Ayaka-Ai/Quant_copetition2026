# 加密因子字段与复现

`crypto_factor.py` 定义30条Qlib公式。`configs/crypto_factor_fields.json` 记录25个输入字段的含义、定义缺口与核对要求；不代表供应商已提供这些字段。运行时可通过 `get_factor_inventory()` 取得每条公式及其依赖，避免另抄一套公式。

## 运行

建议单独建立Python 3.11环境。`requirements-qlib.txt` 与策略的 `requirements-risk.txt` 使用不同NumPy版本，分别安装。

```bash
python -m venv .venv-qlib
# Windows: .venv-qlib\Scripts\activate
# macOS/Linux: source .venv-qlib/bin/activate
python -m pip install -r requirements-qlib.txt
python -m examples.inspect_crypto_factors --available-fields close high low --output outputs/crypto_inventory.json
python -m examples.run_crypto_price_demo
python -m unittest discover -s tests -p test_crypto_factor.py -v
```

盘点命令列出全部30条公式、25个字段与逐因子缺口。传入 `close high low` 时，有6条公式的字段名称齐备；这不是对实际数据的验收。

演示生成2个虚构资产、各96个日线bar，日历包含周末。Qlib读取独立临时 `.bin` 数据，跳过前60个bar后输出72行×6个价格因子至 `outputs/crypto_price_demo/factors.csv`。原始标签为 `close(t+2)/close(t+1)-1`；每个资产最后2行标签应缺失。临时provider运行后删除，输出不提交Git。

测试使用真实Qlib表达式引擎，对6个因子逐点与独立计算比较，核对标签方向、末端缺失和未来价格变化不影响过去因子。合成数据仅验证代码，不产生选因子、IC或收益结论。

## 因子选择与加载

```python
from crypto_factor import CryptoFactorHandler, PRICE_FACTOR_NAMES

# 此前须 qlib.init(provider_uri=已准备好的本地数据目录, ...)
handler = CryptoFactorHandler(
    instruments=["YOUR_ASSET"], start_time="2024-03-01", end_time="2024-06-01",
    factor_names=PRICE_FACTOR_NAMES,
    infer_processors=[], learn_processors=[],
)
```

不传 `factor_names` 保留原30条；选择不能为空、重复或含未知名称。Handler直接引用本仓库的loader类，无需把文件复制进Qlib安装目录。默认学习处理器沿用Qlib的标签截面标准化；核对原始标签或只有一个资产时显式用 `learn_processors=[]`。模型训练的处理器配置应另行固定。

## 字段缺口

| 类型 | 字段 | 接入要求 |
|---|---|---|
| 价格（3） | close, high, low | 同一资产、交易场所、计价币和bar边界；仍需确认数据来源 |
| 价格派生（6） | adx14, di_plus14, di_minus14, hv30, hv50, hv100 | ADX/DI固定Wilder平滑及初值；波动固定收益定义、ddof、年化和单位 |
| 宏观及资金（7） | fed_funds, dxy, cpi_yoy, m2, net_etf_flow, market_cap, ssr | 固定指标版本、资产范围、单位与首次可得时间；ssr的具体定义需确认 |
| 链上（7） | hashrate, active_addresses, cdd_nvt, sopr_above_one, sopr_below_one, sth_supply_profit_loss_ratio, lth_mvrv | 确认适用链和资产；cdd_nvt与SOPR分段字段优先向公式作者确认定义 |
| 情绪（2） | fg_alt, fg_perc | 确认两套指数来源及量纲，不把其他情绪指标直接改名替代 |

每个字段映射至少记录：资产、供应商/端点、单位、频率、时区、bar起止、`available_at`、历史区间、缺失和修订规则。字段名相同不构成映射证据。缺字段保留缺口，不填0凑齐30条。

`Ref(60)` 指provider日历中的60个bar。单独60期收益至少61个价格点；`Mean(Ref(hashrate,60),3)` 至少63个算力点；若hv50基于50个日收益，其60期变化至少111个收盘价。Qlib部分滚动算子会在历史不满窗口时返回值，真实研究须另做完整窗口检查，不能把非空直接当预热完成。

宏观和链上数据须按历史当时实际可得时间对齐，并区分统计期、发布时间与此次下载时间。默认标签不是 `t→t+1` 收益。跨资产共用宏观值不能单凭复制数据产生截面排名；单资产时间序列评价与多资产截面IC也须分开。

## 与策略模块的边界

美股策略仍沿用 `quant_data / quant_signals / quant_portfolio / quant_backtest`；加密因子演示独立运行。市场、数据与预测期限确认后，再约定输出时间及 `SignalScore` 接入，当前不把加密资产送进美股交易日历或账户。
